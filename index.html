Five Brand Creator Automation is a Windows desktop tool used by Vineet Kumar to work with his own YouTube channels. It connects through Google's OAuth authorization flow and the YouTube Data API. It is operated locally with assistance from the creator's Codex environment.

What the tool can do

With the account owner's permission, the tool can read channel information and video details, upload videos, edit titles and descriptions, set thumbnails, schedule eligible private videos, and delete specifically selected videos. API permissions and account eligibility determine which actions are available.

Google sign-in and permission approval happen on Google's website. The tool does not ask for or store Google passwords. Granting access does not itself upload, edit, or delete channel content.
